## This is NOT the Next.js you know

This version (16.3.1) has breaking changes — APIs, conventions, and file structure may all differ
from training data. Read the relevant guide in `frontend/node_modules/next/dist/docs/` before
writing any code. Heed deprecation notices.

## Libraries

- Aceternity UI (https://ui.aceternity.com/components) for components/widgets
- MagicUI (https://magicui.design/docs/components) for components/widgets
- Framer Motion / motion for animation
- lucide-react for icons

## Conventions

- All components must live in `components/`.
- The `components/ui/` folder is reserved for components generated by `npx` (Aceternity or
  MagicUI) — do not hand-write files there.
- The app currently uses mock data (`lib/data.ts`); the goal is to integrate it with the real
  backend API later. Confirm before wiring a live API.

## Run (frontend/)

```bash
npm install
npm run dev
```

- Dev: http://localhost:3000
- Lint: `npm run lint`
